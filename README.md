KORVATH DEEP — a travel poster for a city at the bottom of the sea. A single
Node program paints it from raw pixels: light shafts leaning down from the
surface, a great spiral shell tower ringed with amber portholes, dome houses
at its foot, jellyfish, coral and a rising field of bubbles, with the city's
name set in hand-drawn stroke letters on the dark water. It writes one PNG
to /output/entry.png.

## Run it

```sh
node main.ts
```
